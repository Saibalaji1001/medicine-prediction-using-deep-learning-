# Medicine Prediction Using Deep Learning

## Overview

This project uses deep learning to predict diseases and recommend medicines based on user symptoms. It helps in providing quick medical suggestions using artificial intelligence.

## Features

* Symptom input system
* Disease prediction using neural networks
* Medicine recommendation
* User-friendly interface
* Deep learning model implementation

## Technologies Used

* Python
* TensorFlow / Keras
* Jupyter Notebook
* HTML, CSS
* Machine Learning
* Deep Learning

## Project Structure

```
medicine-prediction-using-deep-learning/
│
├── medicine_prediction.ipynb
├── dataset.csv
├── README.md
```

## How It Works

1. User enters symptoms
2. Model processes input
3. Disease is predicted
4. Medicine is recommended
